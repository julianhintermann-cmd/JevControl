Erste Testversion von **Kairo**, dem nativen KI-Agenten für Windows. Mit **Strg+Alt+K** öffnest du das Eingabefeld und beschreibst die Aufgabe. Kairo erledigt sie mit echten Windows-Aktionen.

## Installation

1. `Kairo-1.0.0-x64.msi` herunterladen und starten. Die Installation erfolgt pro Benutzer, ohne Administratorrechte und ohne vorinstalliertes .NET.
2. **Das Installationspaket ist nicht signiert.** Windows SmartScreen zeigt deshalb „Unbekannter Herausgeber“. Weiter geht es mit *Weitere Informationen → Trotzdem ausführen*.
3. Beim ersten Start den **OpenRouter-API-Schlüssel** eingeben und *Verbindung testen*.
4. Optional für Chrome und Edge: die Erweiterung entpackt laden. Den Ordner `%LOCALAPPDATA%\Programs\Kairo\extension` unter `edge://extensions` bzw. `chrome://extensions` im Entwicklermodus auswählen.

Ausführliche Anleitung: [docs/INSTALLATION.md](https://github.com/julianhintermann-cmd/JevControl/blob/v1.0.0/docs/INSTALLATION.md) · Manuelle Testcheckliste: [docs/TESTING.md](https://github.com/julianhintermann-cmd/JevControl/blob/v1.0.0/docs/TESTING.md)

**Voraussetzungen:** Windows 10 1809+ oder Windows 11 (x64), ein OpenRouter-Konto mit Guthaben.

## Enthalten

- Overlay mit Strg+Alt+K (Hotkey änderbar, Konflikterkennung) und Nothalt mit Strg+Alt+Umschalt+K.
- Planung über OpenRouter und strukturierte Entscheidungen mit **TypeSafe Jev** über die OpenRouter Decisions API.
- Steuerung über:
  - Browser-DOM mit der Kairo-Erweiterung,
  - Windows UI Automation,
  - SendInput als Rückfallebene,
  - Screenshots nur als letzter Ausweg.
- Kairo prüft alle eingetragenen Werte, bevor es absendet. Absenden, Senden, Bezahlen und Löschen geschehen nur nach deiner Freigabe.
- Dateien werden lokal gelesen (PDF, DOCX, XLSX, CSV, JSON, TXT).
- Sicherheit:
  - API-Schlüssel mit DPAPI verschlüsselt,
  - Schutz vor Prompt-Injection,
  - Dateizugriffsgrenzen.
- Oberfläche:
  - Einstellungen mit 9 Bereichen,
  - Aufgabenverlauf mit Kosten,
  - Tray-Symbol,
  - optionaler Autostart,
  - hell und dunkel.

## Geprüft (automatisiert auf Windows, GitHub Actions)

- 100 Unit-Tests, 43 Tests der Browser-Erweiterung, 25 Windows-Integrationstests.
- End-to-End:
  - Kontaktformular aus einer PDF ausfüllen, nativ und in Microsoft Edge, dort sowohl über UI Automation als auch über die Erweiterung,
  - Freigabe vor dem Absenden,
  - Abbruch während der Planung und während des Tippens.
- Live mit echtem OpenRouter-Schlüssel:
  - Jev antwortet in rund 200 ms.
  - Das Planungsmodell füllt das Testformular korrekt aus (23 s, 0,03 USD).
- Installer: Installation, Selbsttest, Deinstallation mit Behalten und mit sicherem Löschen der Daten. Das hier angehängte MSI hat diesen Test vor der Veröffentlichung bestanden.

## Bekannte Einschränkungen

- **Nicht signiert:** Es war kein Code-Signing-Zertifikat verfügbar.
- **Testsystem:** Bisher nur auf Windows Server 2025 getestet (CI), noch nicht auf Windows 10/11-Clients.
- **Browser-Erweiterung:** Sie muss entpackt geladen werden, weil sie nicht im Chrome Web Store bzw. bei den Edge-Add-ons veröffentlicht ist.
- **Dauer der Planung:** Mit dem Standardmodell dauert eine Planungsrunde rund 10 s. Die Zielprüfung ist manchmal zu vorsichtig; dann plant Kairo eine zusätzliche Runde und bittet dich, das Ergebnis zu prüfen.
- **Vision-Fallback:** Die Bildanalyse für Anwendungen ohne Accessibility-Informationen ist noch nicht mit echten Modellen getestet.
- **Administratorrechte:** Anwendungen, die als Administrator laufen, kann Kairo nicht bedienen. Das ist eine Windows-Schutzfunktion.
