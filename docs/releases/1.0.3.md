**Kairo-Erweiterung für Firefox und Zen, von Mozilla signiert.** Damit lässt sie sich dauerhaft installieren und bleibt nach einem Neustart des Browsers erhalten. Die App selbst ist unverändert gegenüber [1.0.2](https://github.com/julianhintermann-cmd/JevControl/releases/tag/v1.0.2).

## Installation

1. `Kairo-1.0.3-x64.msi` über die vorherige Version installieren.
2. **Zen / Firefox:** `Kairo-Firefox-1.0.3.xpi` herunterladen und ins Browserfenster ziehen, oder `about:addons` → Zahnrad → *Add-on aus Datei installieren…* und die Installation bestätigen. Eine vorübergehend geladene ältere Version (über `about:debugging`) vorher dort entfernen.
3. Aufs Kairo-Symbol klicken. Es sollte „Verbunden mit Kairo“ zeigen, solange Kairo läuft. Erscheint „Zugriff auf Websites erlauben“, einmal darauf klicken.

Die Datei ist unter der festen ID `kairo-bridge@jevcontrol` signiert, nicht öffentlich gelistet („unlisted“, zur eigenen Verteilung). Chrome und Edge laden die Erweiterung wie bisher entpackt aus `%LOCALAPPDATA%\Programs\Kairo\extension`.

## Bekannte Einschränkungen

- Zen selbst ist nicht automatisiert getestet, nur Firefox mit derselben Engine; siehe [1.0.2](https://github.com/julianhintermann-cmd/JevControl/releases/tag/v1.0.2).
- Windows-Installer weiterhin nicht signiert (SmartScreen: *Weitere Informationen → Trotzdem ausführen*).
